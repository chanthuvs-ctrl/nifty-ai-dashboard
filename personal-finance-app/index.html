🔗 Phone SMS Webhook Auto-Capture Setup

You can automatically send SMSes from your Android or iPhone directly to this app in real time!

REST API Ingest Endpoint
POST /api/sms/ingest
Header: Content-Type: application/json
Body: { "smsText": "Rs 22579 debited for Home Loan..." }

Option A: Android SMS Forwarder / Tasker / Automate

  1. Install SMS Forwarder or Tasker from Google Play.
  2. Create a trigger on Incoming SMS matching keywords like "debited", "credited", "paid", "UPI", "A/C".
  3. Set Action to HTTP POST to /api/sms/ingest with payload {"smsText": "%SMSB"}.

Option B: iOS Shortcuts (iPhone)

  1. Open Shortcuts App → Automation → New Automation → Message.
  2. Set Sender/Content contains: "debited", "bank", "₹".
  3. Add action "Get Contents of URL" → Method: POST, Request Body: JSON, Key: smsText = Shortcut Input.
